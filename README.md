Como Executar o Projeto
Caso queira clonar e rodar este projeto localmente, certifique-se de ter o Flutter SDK instalado em sua máquina e siga os passos abaixo:

Clone o repositório:
git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git

Acesse a pasta raiz do projeto:
cd SEU_REPOSITORIO

Instale as dependências do projeto:
flutter pub get

Execute o aplicativo (certifique-se de ter um emulador ativo ou utilize o navegador):
flutter run
